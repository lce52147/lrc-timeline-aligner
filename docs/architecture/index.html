這張圖看不到的東西

  • 分層是依模組名稱與拆檔報告分的，不是 graphify 的自動分群（它分出 230 個函式層級的群）。邊數全部來自 graphify。
  • 主圖只畫主幹（17 條線）。幾乎每一層都用到「時間證據核心」「音訊／歌詞」「執行期基礎」，沒有全部畫線；完整的上下游數字在點開方塊後的右側面板。
  • bat／ps1 啟動路徑不在 graphify 圖中，點線是依原始碼補畫的。
  • helper 子行程是用檔案路徑啟動的，不是 import，圖裡沒有邊；虛線是依原始碼補畫的。
  • 審核頁前端 review_page/index.html（2,211 行）不是 Python，沒有進模組統計。審核頁和對齊管線之間只靠報告與 LRC 檔案相連。
  • 執行期才綁定的 callback（例如 report_trust → central_commit）在 import 層級看不到。
  • lyricsee 已不在公開 repo，圖上沒有。
