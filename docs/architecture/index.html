LRC 1.9 架構圖

你給它一首歌的音檔和歌詞（只有文字，沒有時間），它算出每一句從第幾秒開始唱，存成 LRC 檔。音樂播放器讀到 LRC，就能跟著歌聲一句一句亮起歌詞。

它怎麼做到的

  1. 先把伴奏拿掉。只留下歌聲，模型比較好聽清楚。
  2. 讓幾個語音模型各自找每一句的開頭。它們已經知道歌詞，只要找「這幾個字在哪裡」。
  3. 由裁判挑時間。模型意見一致就採用；不一致時，剪那一小段重聽，或找更多模型投票。
  4. 沒把握就說出來。仍然不確定的句子會被標出來，人只要在審核頁聽這幾句，不用整首重聽。

在 37 首人工逐句校對過的歌上，87% 的句子誤差在 0.2 秒內，大約是一個音節的長度。
